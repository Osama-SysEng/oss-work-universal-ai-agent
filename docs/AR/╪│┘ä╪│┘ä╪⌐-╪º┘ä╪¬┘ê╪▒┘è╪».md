# حدود سلسلة التوريد

تُعامل الأرشيفات الإضافية كمراجع لا كمصدر موثوق يُدمج تلقائيًا. بقي مستودع TimescaleDB مشروعًا upstream مستقلًا ولم يُنسخ داخل التطبيق. أضاف أرشيفا Next.js أفكارًا بصرية ومكونات عرض تمت مراجعتها، بينما استُبعدت مسارات API الحية وبيانات seed ومسارات تنفيذ الكود على المضيف.

يحتوي console على `pnpm-lock.yaml`. يجب تثبيت الاعتمادات بواسطة `pnpm install --frozen-lockfile --ignore-scripts` في بيئة بناء مضبوطة، ثم مراجعة الثغرات والتراخيص وإنشاء SBOM وتوقيع artifact. يبقى تثبيت الحزم أثناء التشغيل معطلًا، وأي نظام تحديث لاحق يجب أن يقبل artifacts موقعة مع provenance موثوق ومسار rollback مختبر.

يستبعد الأرشيف النهائي `node_modules` و`.next` وcaches الخاصة بـ Python وقواعد البيانات والسجلات والأسرار وملفات أسرار النشر. يتحقق التغليف من سلامة ZIP وبصمة SHA-256، لكن البصمة تثبت سلامة البايتات ولا تثبت خلو المصدر من الثغرات.
